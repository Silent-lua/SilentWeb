# CLICK CASH (Mod)

Versión web del juego con **1.000.000 × multiplicador** por cada click.

## Cómo funciona

- Empiezas con **0 puntos**
- Multiplicador y mejoras = **iguales al original**
- Cada click suma: **1.000.000 × Multiplicador de clicks**
- Si subes el multiplicador, los puntos por click aumentan

## Jugar online

Cuando actives GitHub Pages, el juego estará en:

```
https://TU_USUARIO.github.io/NOMBRE_DEL_REPO/
```

## Activar GitHub Pages

1. Sube estos archivos al repositorio
2. Ve a **Settings → Pages**
3. En "Source" elige **Deploy from a branch**
4. Branch: `main` (o `master`), carpeta: `/ (root)`
5. Guarda y espera 1-2 minutos
6. Abre el enlace que te aparece

## Archivos

- `index.html` → El juego (se abre solo al entrar a la página)
- `project.zip` → Proyecto por si quieres re-empaquetarlo
- `README.md` → Este archivo
